# 后台管理系统

这是一个借助云宝（客户端）免费交互后，利用所学习到的技术开发的后台管理系统

技术栈为React 18 / 19 + Ant Design + Vite + React Router + Axios + Zustand + 性能 & 工程化知识。

在这里我会完善全部可以学习的知识点，并将知识点全部变为Readme文档，并同步更新到CSDN、掘金、知乎等知识分享平台。

由于我本人也处于一边学习一边摸索的阶段，所以本仓库内的代码如果存在任何问题，欢迎与我联系。

欢迎对本仓库进行fork，用作你个人的学习或者企业级项目的搭建。

## 技术栈

React：18/19，以官方文档内容为主，并会结合实际使用转义部分描述，便于理解。

Ant Design：使用版本为6.4.3，后续版本更新也会新增更新内容

Vite：轻量级的前端构建工具。与webpack相比，上手相对容易。

React Router：目前最新版本为7.8.0，本系统也会尽可能收纳全部路由情况。

Axios：promise网络请求库，后续会接入我自己的node.js后端项目，用来学习其中的部分知识。

Zustand/Redux：第三方状态库的学习将会伴随着后续的选择而进行，如果你对其他第三方状态库感兴趣，欢迎你对本仓库的依赖进行更换。

性能 & 工程化知识：这部分知识比较抽象，涉及到项目的方方面面。因此我也会在本身学习理解的基础上对这部分进行润色，方便你对后续的内容进行学习、理解和使用。
